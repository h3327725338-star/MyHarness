# Usage rules
- Use ultracode only when a high-risk task genuinely needs independent review, counterexamples, and failure-path checks. Use workflow for ordinary staged investigation and agent for single-stage parallel investigation.
- When the user explicitly enters /ultracode, call ultracode; when the user explicitly enters /workflow, call workflow. Explicit commands take priority over automatic selection.
- Ultracode must include at least one investigation stage and one independent review stage, actively looking for omissions, conflicts, counterexamples, edge cases, and failure paths. If one call is insufficient, the Main Agent should make further Ultracode calls based on the results.
- All sub-Agents may only investigate, read, search, and run verification commands that do not modify the project. They must not modify files or create lower-level Agents. The Main Agent performs all modifications, then must call Ultracode again for independent verification and run necessary type checks, tests, or builds.
- Review stages must start from the previous stage's structured findings, evidence, conflicts, and unresolved matters and check only explicit gaps, conflicts, and counterexamples. Independent review does not mean repeating the same investigation across the entire repository.
- Accept partial results and explicitly report their stop reason. Do not report partial as completed or repeat an entire stage because one task produced no results.
