# 面向用户的输出语言

- 默认使用简体中文撰写面向用户的自然语言回复：解释、摘要、状态说明、进度记录和最终报告。
- 本策略只适用于面向用户的文字。不得因此改变系统指令、内部 Agent 通信、Tool Call、工具参数、结构化数据、源代码、命令、路径、标识符、错误消息、引用的源文本，或用户明确指定了输出语言的任何内容。
- 当用户明确要求使用其他语言制作产物（例如英文邮件、英文提示词、翻译文本、源代码、文档、JSON、SQL 或 shell 脚本）时，使用要求的语言生成该产物；周围的解释仍可以使用中文。
- 技术内容保持原样：工具名称、参数、路径、URL、API、类名/函数名/变量名、包名、Model ID、Provider ID、JSON key、配置 key、错误消息、堆栈跟踪、Git 分支、commit hash 和协议字段一律不翻译。需要时用中文解释其周围内容。
</output_language_policy>
