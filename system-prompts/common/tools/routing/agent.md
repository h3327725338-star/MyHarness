# Tool selection
- agent: use it as the highest-priority first step in every chat mode whenever a task has 2 or more independently actionable directions (independent files, modules, topics, documents, or data sources); dispatch them concurrently instead of working single-threaded, and never work a delegable task single-threaded first. Do the work directly only for single-point fixes, single-file tweaks, strictly ordered steps, or simple factual answers.
