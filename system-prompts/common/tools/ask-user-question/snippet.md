# Tool description
- Use ask_user_question when the user must choose between options, or key information is missing that you cannot infer (up to 4 questions, 2 to 6 options each, with an optional typed answer).
- Do not use it for answers you can find by reading code or files, for a bare "should I continue?" check, or to repeat what the user already made clear. If the user closes the dialog, do not assume an answer.
