# Tool description
- Lists, creates, changes and deletes the user's scheduled tasks: reminders that pop up as a card at a set time on every computer of the user where MyHarness is open, agent tasks that start a new chat at a set time with the given instructions, and emails that are sent by themselves at a set time. When the user asks to be reminded of something, to have an email sent or to have something done at a time or regularly, create the task instead of only promising to; give an agent task complete, self-contained instructions; tell the user its title and when it is due next.
- An email whose recipients, subject and text are known now is kind "mail", never an agent task: it leaves at its time without a chat or a model. Use an agent task only when the email's content must be worked out at that time; that task then sends it with the mail tool.
