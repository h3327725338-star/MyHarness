# Tool description
- Control the desktop workspace: list, open (also in the background), close, activate, reorder and restore the file, media and browser tabs of the right-hand panel; drive any number of browser tabs side by side by `tabId`, on screen or not: navigate, read (text, DOM, accessibility tree, interactive elements with their centre points), find, run page scripts, upload a workspace file, save a link as a file (`download`) and read downloads and requests. You browse at a desktop size (at least 1280×800) whatever the width of the user's panel. A click that starts a download waits for it and returns the saved file's path. Use your own mouse and keyboard: `screenshot` shows the tab in the page's CSS pixels, `mouse` clicks, double-clicks, right-clicks, hovers, drags or scrolls at an x/y point of that picture (images and canvases included), `key` presses keys or combinations, `type` types into the focused element. Bookmarked sites are trusted by the user: open them with `bookmark`, sign in with `login` (the app fills the saved login; you never see the password), and their permission requests are allowed automatically; `answer_permission` allows or denies a pending request of any site. Play, pause, seek and set volume on media tabs. Every call reports the state that was reached, and the tool exists only in the desktop app.
