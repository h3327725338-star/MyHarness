# Tool description
- Control the desktop workspace: list, open, close, activate, reorder and restore the file, media and browser tabs of the right-hand panel; navigate and inspect web pages (text, DOM, accessibility tree, interactive elements); click, type, scroll, find in the page and run page scripts; upload a file from the current workspace into a page's file input; take screenshots; read downloads, requests and site-permission decisions; play, pause, seek and set volume on media tabs. Every call reports the state that was reached, and the tool exists only in the desktop app. Granting or revoking a site permission is a user action in the tab, never an Agent action.
