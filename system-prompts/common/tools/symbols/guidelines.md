- Before writing nontrivial code that may already exist, consider find_existing with a short intent, likely names and a narrow path. Read strong candidates before reusing; skip discovery when prior evidence is sufficient or text search is enough.
- find_existing returns leads, not equivalence or proof of absence. Its coverage explains semantic versus lexical evidence; on timeout, keep useful candidates and narrow path/languages instead of repeating a broad slow query.
- Once located, prefer read_symbol for the declaration and necessary context. Follow its source continuation hint when condensed; a paginated or partial result does not mean all source was read.
- Before a contract change, use impact when semantic relations help avoid missed uses. Certain references and possible text matches are separate; partial coverage still needs source and project validation.
- To rename across files, inspect symbols rename_preview and pass its planId to the separate apply_rename tool. apply_rename is not a symbols operation; refused or partial plans need review, not blind retries.
- Use file_symbols for an outline and workspace_symbols for name discovery. A file path selects its language; a directory scopes results; no path searches observed configured languages. Prefer a narrow file/project when a server cannot cover the whole workspace.
- Prefer flat locators: path plus line and character, symbolId from a result, or path plus name for workflow operations. Position inputs and UTF-16 columns are 0-based; displayed path:line is 1-based. Legacy target objects and JSON target strings remain accepted; never invent coordinates or IDs.
- Follow nextCursor with the same query to retrieve complete entries without rerunning the server. Increase maxChars for an oversized entry, or use its source location; queryCompleteness describes the server result, not the current page.
- Treat unsupported hierarchy, timeout, incomplete_query and diagnostics_not_published as limitations, never a successful empty hierarchy or clean build. Diagnostics opens/synchronizes the file but missing or versionless snapshots do not replace project type checks and tests.
- Pass only fields supported by the operation. Do not force symbols for plain-text work; on unavailable or slow semantic queries, continue with source/text tools and disclose their limits.
