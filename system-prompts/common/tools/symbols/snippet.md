# Tool description
- Query code structure with explicit source and completeness: name discovery, definitions, references, implementations, calls, supported type hierarchies, outlines and synchronized diagnostics. Use flat path/line/character (0-based), a returned symbolId, or path/name for read_symbol, impact and rename_preview; legacy target objects remain accepted. find_existing ranks reuse candidates with coverage, read_symbol reads one declaration, impact separates certain references from possible text matches, and rename_preview creates a plan for the separate apply_rename tool. Follow nextCursor for more entries. Use ordinary text/file tools when they suffice; unsupported or partial output never proves absence or a clean build.
