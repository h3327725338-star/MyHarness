# Tool description
- Query code symbols and relationships: find symbols, definitions, references, implementations, call chains, type hierarchies, file outlines, and compiler diagnostics by name or exact position, returning file:line locations. Workflow operations: find_existing ranks existing implementations for an intent with evidence, read_symbol returns one symbol's source with its signature, decorators and overloads, impact lists certain and possible uses before a contract change, rename_preview plans a semantic rename. Use grep/find/ls for plain-text matching.
