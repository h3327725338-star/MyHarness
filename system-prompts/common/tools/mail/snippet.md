# Tool description
- Read, search, send and organize mail in the user's connected Gmail and Outlook mailboxes.
- To send a new email, give only message (to, subject, text) and no path: it goes out within seconds through the connected mailbox, or without one through the Gmail or Outlook website the user is signed in to in the built-in browser. Never fill a web compose form yourself.
- Without a mailbox connected here, read and organize mail with the workspace tool on the web mailbox the user is signed in to in the built-in browser.
