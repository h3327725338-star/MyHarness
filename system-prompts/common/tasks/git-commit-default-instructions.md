# Commit
- Before committing, check the changes for secrets: API keys, access tokens, passwords, private keys, cookies, connection strings that contain credentials, and personal absolute paths such as a user's home folder. If any is found, stop the commit and list each file and what was found.
- Write a detailed description: a concise title, then a body grouped by feature that says what changed and how it affects users. Match the language of the recent commit history.
